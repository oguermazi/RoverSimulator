# Rover Simulator

This project is the solution for the Mars Rover movement simulation problem as described in `rover.md`

## Overview
The application enables a simulation where rovers can be positioned on a grid and controlled via a list of instructions. It includes logic for movement, rotation and ensures rovers stay within grid bounds and do not occupy the same space.

## Project Structure
- `rover.md`: Contains the problem description and specifications.
- `input.txt`: Contains the input configuration and command sequences to be processed by the program.
- `src/`: Contains the core implementation.
